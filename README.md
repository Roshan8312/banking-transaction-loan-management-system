# Banking Transaction & Loan Management System

A database management project developed using MySQL to manage banking customers, accounts, transactions, and loans. The project demonstrates relational database design, normalization, SQL queries, joins, subqueries, aggregate functions, views, and stored procedures.

## 📌 Project Overview

The Banking Transaction & Loan Management System is designed to organize and manage banking-related data using a relational database.

The system maintains information about customers, bank accounts, transactions, and loans while providing SQL-based operations for financial analysis and reporting.

## 🎯 Objectives

- Design a structured relational database for banking operations.
- Manage customer and account information.
- Record and analyze banking transactions.
- Manage loan-related information.
- Apply database normalization principles.
- Use SQL queries for financial reporting and analysis.
- Demonstrate advanced SQL concepts such as joins, subqueries, views, and stored procedures.
